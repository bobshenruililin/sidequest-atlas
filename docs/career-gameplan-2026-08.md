## 2. Playbook to steal (eleven tactics)

These transfer. The logos do not.

1. **Recruiting runs 9–12 months ahead of the work.** Summer 2028 windows open ~Jul 2027 — while Bob is in LiA. Materials and referees must be ready *before* June 2027.
2. **Early programmes are conversion funnels**, not jobs. Read the return path, not the stipend.
3. **Externships / insight days** (1–5 days) put a name in a pipeline cheaply. HK almost does not run these for public health — that absence is Vehicle 2.
4. **Term-time part-time (5–15 h/week)** is the only structurally free slot in 2026/27.
5. **Research is the internship that ports across borders.** Output > headcount slot. This is already Bob's lane.
6. **Referrals are mechanical.** Warm a human who can move in 48 hours *before* a posting opens. Use Laidlaw / T&N / St John's / SPH as brokers, not as honours.
7. **Artifacts substitute for permission.** For GHD that means a dataset, map, methods note, or accepted abstract — not a GitHub toy.
8. **Winternships exist.** LINK-S occupies Dec–Feb 2026/27. Treat that as a decided trade.
9. **Matching fellowships** (Coding it Forward, etc.) are US-gated. The *model* — a community that brokers placements into government offices — is Vehicle 2.
10. **Ambassador programmes are a time tax.** Microsoft Learn / OpenAI Student Collective / Canva / Red Bull: decline unless under 2 h/month *and* a named product-team or data door. Martin Scholar optics: filler dilutes.
11. **Community lists are triage inputs with a half-life.** Verify every fact at the official URL. Build the HK analog in LearnAI instead of starring US lists.

LuisaE's bonus tips that survive translation: LinkedIn hygiene, one referee who will actually refer, mock the *real* interview type (policy memo / R / epidemiology, not LeetCode), do not fear a small number of sharp rejections.
