# Service hours — Q13 / Q14

Status: park. Count certificates before choosing a radio band.

## Q13 radio rule

Count certificates/timesheets first, then select the **lowest true band** containing the verified total.

Count only completed, documented, unpaid, non-credit service hours — actual duty time, non-overlapping, within the application’s eligibility period.

Do **not** select “more than 300 hours” unless verified eligible hours strictly exceed 300.

## Student Coordinator

Title alone is not service. Unpaid and non-credit: count documented duty hours. Paid, stipend, or credit-bearing: do not count unless the form rules permit. Mixed: count only separately documented eligible hours.

## When “more than 300” is true

Only if the sum of non-overlapping, eligible, documented hours is greater than 300. Estimates cannot bridge the gap.
