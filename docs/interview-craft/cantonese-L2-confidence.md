# Cantonese as L2 — confidence for a Mandarin/English thinker

## The real problem (technical)

You are not “bad at Cantonese.” You are running **speech production in a language you do not primarily think in**, under evaluation. That taxes:

1. Conceptualization (what to say)  
2. Formulation (Canto words/tones/particles)  
3. Articulation  
4. Self-monitoring (did I sound local? wrong?)  

Anxiety + monitoring → working-memory collapse → blank or Mandarin leak.

Research-adjacent findings useful here:

- Speaking is the peak anxiety modality in L2.  
- Social strategies (ask slow-down, ask correction) work better than pure drilling under stress.  
- Pre-task planning + **formulaic chunks** reduce overload.  
- Pauses are cognitive resources, not moral failures.  
- Treat Canto as a **distinct language system**, not “broken Mandarin + shame” — shame adds affective load.

## Operating policy for the panel

| Mode | When |
|------|------|
| **English** | Default; complex answers; research; hard Qs |
| **Mandarin** | If panel switches; nuance you need; you’re stronger |
| **Cantonese** | Greeting, short relational answers, already-chunked stories |
| **Switch request** | When precision decays — polite, once, no self-flagellation |

**Belonging is not proven by suffering in Canto.** Precision + honesty > accent theatre.

## Formulaic scaffolds (memorize these, not paragraphs)

| Function | Cantonese | Use |
|----------|-----------|-----|
| Headline | 我最想講嘅重點係…… | Start any answer |
| Example | 有一個具體例子…… | After headline |
| Learning | 我喺呢件事入面學到…… | Close story |
| Priority | 對我嚟講，最重要嘅係…… | Values / why T&N |
| Compress | 如果用一句講…… | When interrupted |
| Pause | 可唔可以俾我諗一諗先？ | WM drop |
| Slow down | 唔好意思，可唔可以講慢少少？ | Comprehension |
| Switch EN | 呢個問題我想用英文答，會表達得準確啲，可以嗎？ | Precision |
| Switch CMN | 这个问题我想用普通话回答，会表达得更准确，可以吗？ | Precision |

## Reduce monitoring (in the moment)

1. Think only the **headline noun** (服務 / 研究 / 返香港).  
2. Speak **two sentences**, then pause.  
3. Do **not** replay the previous sentence for tone errors.  
4. If Mandarin leaks, smile once → scaffold → continue or switch.  
5. Audience values **coherence** over native accent in a Foundation panel.
