# What to paste (complete recipes)

Do **not** paste `DO-NOT.md` after the constitution. Closed lanes are **§12 of** [CONSTITUTION.md](CONSTITUTION.md). That file is a complete rules message.

Named Grok Bots keep **separate chat memory**. They share the **computer** (files, logins). Put the constitution on disk once; then each specialist can be a role-only paste.

## Before any paste

Copy this folder onto the Grok computer:

```text
docs/opportunity-os/   →   ~/opportunity-os/
```

At minimum: `CONSTITUTION.md`, `templates/`, `bots/`, `watchlist/`, `plays/`.
