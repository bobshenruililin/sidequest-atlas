# Layout (this folder is the computer)

After you copy `docs/opportunity-os/copy-to-grok/` to `~/opportunity-os/`, the tree is:

```text
~/opportunity-os/
  START-HERE.md
  PASTE.md
  CONSTITUTION.md
  FIRST-HANDOFF.md
  DO-NOT.md                 # skim only — do not paste
  voice-style.md
  canon.md                  # identity; no phone, no UID
  opportunities.csv
  outcomes.md
  bots/
  watchlist/
  plays/
  schemas/
  claims/
  artifacts/
  resumes/
  queue/pending/
  queue/approved/
```

Treat the Grok computer as **account-scoped**. Files and logins are visible to every Bot. Do not sync filled `queue/` back to public git if it contains unpublished addresses.
