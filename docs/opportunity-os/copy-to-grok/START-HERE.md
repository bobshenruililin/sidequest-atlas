Copy this onto the **Grok cloud computer**, not your laptop.

```text
In this repo:   docs/opportunity-os/opportunity-os.zip
On the Bot:     unzip in /workspace → /workspace/opportunity-os/CONSTITUTION.md
```

Grok’s durable disk is `/workspace`. `~/opportunity-os` is the wrong default.

**Keep** Settings → Agent → Execution on Local Computer at **Never allowed**. If Scout says it “cannot touch local files,” that is expected. Do not let it invent a skeleton.
