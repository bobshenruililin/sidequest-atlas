# Question map

Recurring questions that cut across themes. Use before hunting quotes.

## Kissinger diagnostic (master loop)

1. Sources of well-being? Of decay?  
2. Preserve / adapt / discard which inheritances?  
3. Which objectives deserve commitment? Which prospects reject despite temptation?  
4. Can the society (or self / cohort) tolerate sacrifice toward a worthier future?

## Path-specific loops

| Loop | Questions |
|------|-----------|
| Craft | What would “job well for its own sake” look like in heat-health / CHP-facing work? |
| Mainland | What did Gansu revise that a Hong Kong seminar could not? |
| Boundary | Which standards differ across the seam — and which differences are unknown to me? |
| Travel | What comparison question did this trip answer? What cannot transfer? |
| Community | Who became more capable because I was there? |
| Ambition | Whose cost am I proposing? Do I bear comparable risk? |
| Revision | What evidence would make me drop a beloved claim? |

- Scene · Tension · Diagnosis · Choice · Cost · Revision · Return?
