# Wisdom Corpus — Leadership, Judgment, Return

**Purpose:** A working system for maturity — not a quotation wallpaper.  
**Primary use:** Reflect why join a leadership cohort in transition (e.g. Tung & Ngai); deepen judgment for cross-boundary public-health craft.  
**Identity hinge:** high-craft HK undergraduate; Mainland embed; travel for comparison not escape; return usable things to Hong Kong via scholar community.

> Leadership is most essential during periods of transition…  
> — Henry Kissinger, *Leadership* (entry point; see `themes/10-transition-and-judgment.md`)

## How to read this folder (technical rule)

1. A **quote is a claim**, not a decoration.  
2. Reconstruct argument → stress-test → transfer to HK / your life → decide.  
3. Prefer **one claim well** over ten names dropped.  
4. Interview use: hide scaffolding; speak scene → tension → choice → cost → return.  
5. If a line’s main use is to impress, **retire it**.

Full method: [`method/claim-protocol.md`](method/claim-protocol.md) · Interview: [`method/interview-use.md`](method/interview-use.md) · Failures: [`anti-patterns.md`](anti-patterns.md)
