# Claim protocol (technical method)

The unit of curation is a **claim**, not a quotation.

## Three passes

### Pass 1 — Recover
- Reconstruct the argument before extracting a line.  
- Note audience, period, problem, key terms.  
- Check edition / translation / location.  
- Separate author’s claim from rhetoric.

### Pass 2 — Stress-test
1. What would falsify or weaken it?  
2. Strongest rival explanation?  
3. Over-generalization risk?  
4. Who would describe the situation differently?  
5. Who gains power if adopted?  
6. Hidden costs / sacrifices?  
7. Reversible?  
8. Later evidence?

### Pass 3 — Transfer
Map: original institution → actors → power → conditions → mechanism → proposed HK application → differences that break the analogy.  
Farther transfer ⇒ lower confidence.

## Claim types

| Type | Test |
|------|------|
| Descriptive | Accurate / representative? |
| Causal | Mechanism vs rivals? |
| Normative | Which values? |
| Strategic | Under what conditions? |
| Conceptual | Clarifies or renames? |
| Analogical | Similar on dimensions that matter? |

## Provenance tags

`user-supplied` · `directly-sourced` · `inferred` · `independently-verified`

Never put quotation marks around a paraphrase.

## Interview-ready only when you can
- explain without quoting;  
- state a serious objection;  
- name transfer limits;  
- connect to a concrete decision.
