# Interview use (no name-dropping)

## Hidden scaffolding

Spoken answer structure:

1. **Scene** — specific situation  
2. **Tension** — two legitimate goods in conflict  
3. **Diagnosis** — institutional / human mechanism  
4. **Choice** — what you did or would do  
5. **Cost** — what was risked or left unresolved  
6. **Revision** — what changed in your thinking  
7. **Return** — usable to others / Hong Kong

## Translation table

| Corpus idea | Speak as |
|-------------|----------|
| Value pluralism | Name the two goods that conflicted |
| Adaptive challenge | Why expertise alone was insufficient |
| Tacit knowledge | What practice revealed that instruction did not |
| Path dependence | Which inherited rule constrained action |
| Contact zone | Unequal expectations across settings |
| Comparative fieldwork | Observation + rival explanation + transfer limit |
| Ethics of responsibility | Foreseeable cost and who bears it |
| Knowledge return | Concrete artifact / practice / benefit |

## Constraints

- ≤1 conceptual hinge per answer.  
- Do not call yourself a leader; describe responsibility taken.  
- Mention a thinker only if asked about reading — then give one useful idea **and** one limit.  
- Reading does not prove character.
